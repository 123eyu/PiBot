# 记忆验收

真实模式由 Claude 在沙箱外运行。入口使用真实 `brain-app.startBrain`、实际 agent 会话、RPC、policy 和后台记忆队列。假模式脚本化模型回复，并注入拒绝命令的执行目标，使命令隔离探测不影响记忆验收；真实模式保留本机执行目标。

```sh
node tools/fake-llm/acceptance/memory/index.ts
```

逐项输出 `ok / FAIL` 及固定判定原因，共九项；任一失败退出 1。默认每项 240 秒（`--timeout`，单位秒，100–3600），整理保留产品首次 90 秒扫描。归档后重启同一临时 brain，使提炼走正常启动扫描（5 秒），不缩短产品定时器，不调用私有 drain。

```sh
node tools/fake-llm/acceptance/memory/index.ts --real \
  --base-url https://api.deepseek.com/v1 --model deepseek-chat \
  --input-price <当前输入美元每百万token> --output-price <当前输出美元每百万token> \
  --cache-read-price <当前缓存读取美元每百万token> --cap-usd 0.3
```

密钥预先由负责人放入 `PIBOT_EVAL_API_KEY`；脚本不读任何其他凭据，不接受密钥参数或认证 header。`--api` 支持和 `pnpm eval roles --real` 相同的四类 API，`--header Name:value` 只接受非认证 header。价格参数名称和单位同 roles，运行者填写实际价格；未填真实价格即拒绝。每次模型 HTTP 请求（含重试和辅助模型）先累计保守的输入 UTF-8 字节数加开销、输出上限费用，不依赖缓存折扣，不退还预留；达到上限或无法确定输出上限即拒绝，可能比实际花费更早停止。`reservedUpperBoundUsd` 是预留上界，不能当厂商账单。

第 10 项另经 `sort-lifecycle.ts` 覆盖审查回归：真实管理 RPC 清空「关于你」/删除单条来源后，关联目标改写不再 pending，后来编辑的正文和 why/how 不受遗留确认影响；停库移除依赖夹具后，目标提议自身 CAS 仍拒绝覆盖。客户端沿 renderer 共用运行对象模拟异常回复及关闭，确认专用取消只发送一次、费用保留、没有后续模型请求，并延迟排空回执证明客户端 Promise 持续等待；同时核对 sort/cancel 协议超时均超过 300 秒。超时场景用受控异常回复代替实际等待 120 秒，Electron 真实桌面传输仍需窗口验收。

在途取消夹具同时等待维护行的 token 预留和假服务接收端的本轮请求。预留发生在异步派发之前，只等 `tokens>0` 就取消可能留下未消费的 `hang`，让后续分类读到错误脚本；这不表示目标提议被版本保护或过期逻辑移除。来源删除和孤立 CAS 场景继续要求先产生一个移动，不能放宽该断言。

资源与权限：父进程创建独立临时根，Worker 持有 brain / SQLite / 假服务；保留真实 HOME 环境值但只给 brain 显式临时 dataDir，host 凭据检测为空；真实 key 仅临时内存加密保存。除记忆与聊天读取外，文件、命令、电脑、外发、网络工具等通过真实权限设置拒绝。假模型在服务HTTP接收入口记录结构；真实模式经127.0.0.1本地中继统一记录与费用预留，仅转发本次配置源站，禁止重定向，带取消与90秒期限，不依赖SDK是否使用全局fetch。Worker 的原始 stdout/stderr 被丢弃，只转发脚本结构化结论；取消、超时或执行者异常由父进程终止 Worker，确认退出后才删临时根。无法确认退出时保留目录并报 FAIL，不伪称清理完成。没有保留数据开关。
