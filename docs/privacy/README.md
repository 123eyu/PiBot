# Pi Bot 隐私说明 · Pi Bot Privacy Notes

Pi Bot 不加遥测：聊天、文件和密钥留在你的电脑上，只发给你为工作选定的服务。下面的清单列出 Pi Bot 可能发起的每一项对外连接：发给谁、发什么、什么时候、默认开不开、怎么关。

Pi Bot has no telemetry: chats, files and keys stay on your computer and go only to the services you choose for the work. The list below covers every outbound connection Pi Bot can make: who receives it, what is sent, when, whether it is on by default, and how to turn it off.
